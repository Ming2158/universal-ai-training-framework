# UATF V1.0.0 功能清单

> 本文按 Git 标签 `v1.0.0` 对应的正式版本整理，说明该版本已经能够实现的功能及其边界。当前仓库 `main` 分支包含少量标签发布后的未发布改动，见文末说明。

## 1. 产品定位

UATF（Universal AI Training Framework，通用 AI 训练框架）V1.0.0 是一个基于 PyTorch 的本地**图像分类训练与评估框架**。它将数据集读取、模型构建、训练验证、最佳模型评估和结果保存串成一套流程，可通过 YAML 配置和本地 Gradio 网页界面启动。

支持两种分类任务：

- **单标签分类**：每张图像对应一个类别，例如“猫”或“狗”。
- **多标签分类**：每张图像可同时对应多个标签，例如一张图像同时具有“室内”和“人物”标签。

典型流程：准备数据集 → 配置任务和训练参数 → 训练并验证 → 评估最佳检查点 → 保存指标、预测和图表。

## 2. 功能总览

| 模块 | V1.0.0 已实现的能力 |
| --- | --- |
| 任务 | 单标签图像分类、多标签图像分类 |
| 数据 | 按类别文件夹读取；单标签 CSV；多标签二值 CSV；数据检查；可复现的随机训练/验证划分 |
| 模型 | ResNet50、ConvNeXt-Tiny、EfficientNet-B0、ViT-B/16；可选 torchvision 预训练权重 |
| 训练 | PyTorch 训练与验证循环；Adam 优化器（配置驱动入口）；StepLR；提前停止；可选 CUDA AMP |
| 设备 | CPU、CUDA GPU，或自动选择可用设备；单机单设备训练 |
| 检查点 | 保存最佳和最近检查点；Python Trainer API 支持恢复训练 |
| 评估 | 分类指标、逐类指标、预测结果 CSV、训练曲线、混淆矩阵或 ROC 曲线 |
| 运行入口 | YAML 配置命令行；本地 Gradio 网页界面；可复用 Python API |
| 实验记录 | 保存生效配置、数据集摘要、模型和环境信息、训练历史、评估指标、日志与模型文件 |

## 3. 数据集与任务

### 3.1 文件夹数据集

单标签分类可按类别分别建立目录，每个目录中放入该类别的图像：

```text
dataset/
  cats/
    cat-001.jpg
  dogs/
    dog-001.jpg
```

也支持显式提供训练集和验证集目录。两边的类别目录必须一致；如果只提供一个数据集，框架可以按配置中的验证集比例进行随机划分。

### 3.2 CSV 数据集

- **单标签 CSV**：包含 `image_path,label` 两列，每行描述一张图像及其类别。
- **多标签 CSV**：包含 `image_path` 列，以及一个或多个标签列；标签值必须是 `0` 或 `1`。
- 图像路径可相对于 CSV 文件或指定的图像目录解析。常见布局是将 CSV 和 `images/` 目录放在同一数据集目录中。

### 3.3 数据读取和校验

- 检查数据路径、目录、CSV 列、行格式、标签值、重复图像路径和空数据集等常见问题。
- 可校验图像是否能够读取；图像读入后统一转换为 RGB。
- 提供缩放、张量转换和归一化预处理，可配置图像尺寸及 RGB 均值、标准差。
- 数据加载通过 PyTorch `Dataset` 和 `DataLoader` 提供给训练器。
- 随机划分使用指定随机种子，训练集和验证集样本索引互不重叠。

## 4. 模型

V1.0.0 内置以下 torchvision 图像分类模型：

| 配置名称 | 模型架构 |
| --- | --- |
| `resnet50` | ResNet50 |
| `convnext` | ConvNeXt-Tiny |
| `efficientnet` | EfficientNet-B0 |
| `vit` | ViT-B/16 |

框架会根据数据集类别数调整分类头输出。可以选择从随机初始化开始训练，也可以启用 ImageNet 预训练权重进行迁移学习；首次使用预训练权重时，可能需要下载权重或使用本地缓存。

模型注册表和 Python 模型构建接口为增加其他 PyTorch 图像分类模型提供扩展点。

## 5. 训练

### 5.1 训练参数

通过配置可设置任务类型、数据路径、图像大小、模型、预训练开关、训练轮数、批次大小、学习率、随机种子、数据加载进程数、运行设备、监控指标和输出目录等。

配置驱动的命令行流程使用 Adam 优化器。可启用或关闭以下训练功能：

- **StepLR 学习率调度**：按配置的间隔和衰减系数调整学习率。
- **提前停止**：在指定验证指标连续若干轮未改善时停止训练。
- **CUDA 自动混合精度（AMP）**：可选功能，仅用于 CUDA 设备；默认关闭。
- **随机种子控制**：设置 Python、PyTorch 和 CUDA 随机种子，并设置 cuDNN 确定性选项。不同硬件、软件版本和数据环境下仍不保证逐位完全相同的结果。

### 5.2 训练与验证

每轮训练后在验证集上计算损失和所配置的指标，并记录学习率和耗时。训练器会在训练结束条件满足时退出，并根据所选监控指标更新最佳检查点。

### 5.3 检查点与恢复

- `best_model.pth`：监控指标表现最佳的模型，可用于最终评估或后续推理。
- `last_model.pth`：最近完成训练轮次的状态，可作为恢复训练的起点。
- 检查点可包含模型、优化器、调度器、AMP、提前停止、轮次和随机数生成器状态。
- Python `Trainer.resume()` API 可从最近检查点恢复后继续训练。
- V1.0.0 命令行参数没有提供恢复训练选项；恢复需通过 Python API 调用。

## 6. 评估与结果

训练结束后，评估流程加载最佳检查点，在验证集上重新计算预测和指标。

### 单标签分类

- 总体准确率（Accuracy）。
- 宏平均 Precision、Recall、F1，以及逐类别 Precision、Recall、F1 和样本数。
- 混淆矩阵和逐样本预测置信度、类别概率。

### 多标签分类

- 宏平均和微平均 Precision、Recall、F1。
- 宏平均和微平均 ROC-AUC，以及逐标签指标。
- 可配置二值判定阈值，默认值为 `0.5`。
- 汇总 ROC 曲线和逐标签 ROC 曲线。

### 每次训练的主要输出

```text
outputs/experiment_001/
  config.yaml                 # 合并并生效的配置
  metrics.json                # 任务、模型、数据、训练历史、评估和环境信息
  predictions.csv             # 验证样本预测、目标值和概率
  best_model.pth              # 最佳模型
  last_model.pth              # 最近训练状态
  logs/
    train.log                 # 训练日志
  plots/
    loss_curve.png            # 训练/验证损失曲线
    metric_curve.png          # 训练指标曲线
    confusion_matrix.png      # 单标签分类结果
    roc_curve.png             # 多标签汇总 ROC 曲线
```

多标签任务还会为各标签生成单独的 ROC 图。预测 CSV 按 DataLoader 的遍历顺序记录样本索引；当前数据适配器不在预测结果中保存原始图像路径。

## 7. 使用入口

### 7.1 配置驱动命令行

V1.0.0 命令行从 YAML 配置启动训练，并可用命令行参数覆盖部分常用配置：训练轮数、批次大小、学习率、随机种子、运行设备和输出根目录。配置加载器会合并默认值、检查未知配置项、校验参数范围和模型名称。

正式版本的命令行入口要求提供 `--config`。它没有交互式配置向导。

### 7.2 本地 Gradio 网页界面

本地网页界面提供以下操作：

- 选择单标签或多标签分类任务。
- 上传 ZIP 格式数据集并由界面准备训练配置。
- 选择内置模型、训练轮数、批次大小、学习率和运行设备。
- 查看训练进度、当前轮次、损失、主要指标及日志。
- 查看结构化评估结果，并下载最佳模型文件。

单标签 ZIP 的根目录应包含类别子目录；多标签 ZIP 的根目录应包含 `annotations.csv` 和 `images/`。界面调用同一套命令行训练流程，训练产物保存在本地 `outputs/` 下。界面本身没有预训练权重开关，上传训练使用随机初始化模型。

### 7.3 Python API

框架提供可复用的数据集适配器、模型构建、任务损失、训练器、检查点恢复、评估和结果保存接口。Python API 可用于自定义训练流程；`Trainer` 可接收调用方提供的 PyTorch 模型、损失函数、优化器、调度器和指标函数。

## 8. 已知限制与未包含功能

- 仅支持图像分类，不支持目标检测、图像分割或其他视觉任务。
- 训练在本地单机单设备执行；不提供分布式训练或多 GPU 训练流程。
- 数据集划分是随机划分，不支持分层抽样或按患者、视频等分组划分。
- CLI 不提供恢复训练命令；需使用 Python `Trainer.resume()`。
- 实验记录提供数据集路径、格式、样本数和标签等摘要，不会对每个数据文件计算内容哈希。
- 不包含托管式实验管理服务，也不包含模型在线服务或独立部署平台。
- 随机数据增强不属于 V1.0.0 内置预处理流程。
