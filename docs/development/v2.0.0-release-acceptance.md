# UATF V2.0.0 Release Acceptance

**Verification date:** 2026-10-16  
**Release version:** `2.0.0`  
**Verification scope:** local source tree, automated tests, application construction, package build, and available CUDA device

This is the current release acceptance record. The [Phase 8 acceptance report](v2.0.0-phase8-acceptance.md) is a dated snapshot from 2026-10-15 and preserves what was known at that time. This record adds the 2026-10-16 verification and keeps browser-only gaps explicit.

## Release Contents

- Package metadata in `pyproject.toml` and `uatf.__version__` is `2.0.0`.
- `CHANGELOG.md`, English and Chinese READMEs, release notes, migration guide, architecture guide, GUI documentation, and versioning policy describe V2.0.0.
- `v1.0.0` remains unchanged. User data, model outputs, virtual environments, and historical pytest directories were preserved. Old pytest temporary directories are excluded from Git by `.gitignore`; they were not deleted.
- The project now documents its seven-page Gradio workspace and maps existing GUI capabilities to their new locations in `gui-ux-audit.md`.

## GUI and Browser Limitations

The application successfully constructs, and an earlier local server verification returned HTTP 200. The Gradio auto-review/browser path has not provided a reliable, approved way to run the final browser acceptance after the latest styling changes. No alternate browser, direct HTTP probe, or Playwright/CDP route was used to bypass that approval result.

Therefore the following are **not verified against the final browser build**:

- Final repaired spacing, empty-state borders, unified background colors, and sidebar divider placement.
- Responsive layout at 1920, 1440, 1366, and approximately 1024 pixels.
- Browser navigation while training remains active, stop/resume, refresh of the current experiment/model asset, evaluation, inference, and file downloads.
- Persistence and visible state after restarting the GUI.

User screenshots and prior feedback document the original defects and drove the final CSS changes, but those screenshots predate the final fixes. They are not presented as proof that the current rendering is correct. The full browser acceptance checklist remains in [Phase 8 GUI UAT](v2.0.0-phase8-manual-gui-uat.md).

## Environment and Scope Limits

- Verified runtime: Windows, Python 3.12.14, PyTorch 2.7.1+cu128, torchvision 0.22.1+cu128, Gradio 6.29.1, psutil 7.2.2.
- Python 3.10 and 3.11, CPU-only installation, external pretrained-weight downloads, and clean network installation were not tested in this run.
- GPU tensor smoke passed; complete GUI CUDA training was not performed in this acceptance run.
- The full suite uses synthetic datasets and small models; it is not a model-quality benchmark.
- The browser-dependent GUI workflows above remain open UAT items. Automated tests and application construction do not substitute for them.
