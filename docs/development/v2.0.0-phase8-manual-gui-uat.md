# UATF V2.0.0 Phase 8：GUI 人工验收（简版）

自动化测试已覆盖后端流程；这里只需在本机浏览器走一遍主要 GUI 流程。使用非敏感的小型图片数据集。成功步骤不必逐项截图；只需回报通过/失败，失败时附错误截图。

## 操作

1. 在项目根目录启动：

   ```powershell
   .\.venv\Scripts\python.exe -m app.app
   ```

   打开终端显示的本机地址。若没有 `.venv`，使用安装了项目依赖的 Python 执行 `python -m app.app`。

2. 数据集：进入“数据集”，先输入不存在的路径并点“导入并检查数据集”，确认报错；再导入有效的 `image_folder`。数据集至少两个类别，每类数张图片。查看类别统计和原图/预处理图，点一次“下一张”确认预览切换。

3. 配置和训练：进入“训练”，先把 Learning Rate 设为 `0` 后点“开始训练”，确认配置被拒绝；再设回 `0.001`，使用 `cpu`、3 Epoch、Batch Size 4、缩放尺寸 64，开始训练。确认自动进入“训练监控”；运行中切换到实验管理再返回，确认任务进度/日志/曲线继续更新；等训练完成。

4. 停止和恢复：启动一个较长训练，在“训练监控”点“停止训练”。确认任务最终为 `Stopped` 且实验详情中有 `last_model.pth`。在实验管理载入该实验配置，将 `training.epochs` 设为检查点 Epoch 加 1，将 `training.resume_from` 指向 `last_model.pth`，启动新实验并确认恢复成功。

5. 历史、评估和推理：刷新实验和模型资产，打开训练详情并加载模型。进入“评估与推理”，用同类别目录结构的独立带标签图片运行评估；再分别试单张图片和至少两张图片的批量推理，确认批量 CSV 可下载。

6. 持久性：等任务结束，关闭 GUI 终端中的服务（`Ctrl+C`），重新启动并打开页面。在工作台刷新近期任务；在实验管理和模型管理刷新资产，确认历史、报告、日志、检查点仍可查看。不要删除或移动 `outputs`。

GUI 没有独立的配置校验按钮；配置错误是在点击“开始训练”时检查。若机器没有 CUDA，CPU 流程即可；若有 CUDA，可额外用 `cuda` 跑一个短任务并回报结果。

## 回报

请用一行回报每项结果：`数据集检查 / 参数校验 / 实时训练 / 停止恢复 / 历史资产 / 独立评估 / 单张推理 / 批量 CSV / 重启持久性`，分别标记通过、失败或未执行。

成功时只需附以下截图：

- 数据集检查成功，能看到类别统计和预览。
- 训练完成，能看到指标或曲线。
- 独立评估结果。
- 批量预测表和 CSV 文件控件。
- GUI 重启后的实验历史和模型资产。

另附 Python、PyTorch、Gradio 版本和设备（CPU 或 GPU 名称）。失败项只需补该项错误截图及任务 ID；遮盖用户名和私有路径，不要发送原始图片或模型文件。
